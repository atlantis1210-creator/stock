تشغيل التطبيق كتطبيق PWA يعمل بلا إنترنت
=========================================

الطريقة الأسهل: GitHub Pages (مجاني)
1) ادخل على github.com وأنشئ حساباً ثم مستودعاً جديداً (New repository) باسم مثل: stock-app  — اجعله Public.
2) اضغط Add file ← Upload files، واسحب كل محتويات هذا المجلد (index.html, sw.js, manifest.json، ومجلد icons) ثم Commit changes.
3) من Settings ← Pages: اختر Branch = main و Folder = /(root) ثم Save.
4) بعد دقيقة يظهر الرابط: https://اسم-المستخدم.github.io/stock-app/
5) افتح الرابط من Chrome على الموبايل (مرة واحدة بوجود إنترنت) ثم القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
   بعد ذلك يعمل بلا إنترنت (يحفظ التطبيق مكتبة قراءة الإكسيل والخطوط تلقائياً عند أول فتح).

ملاحظات
- الملف التطبيق لا يرفع بياناتك لأي مكان؛ كل شيء يُحفظ داخل متصفح الهاتف.
- المستودع Public يعني أن كود التطبيق ظاهر للجميع، لكن بياناتك لا تُرفع إليه.
- عند تحديث التطبيق مستقبلاً: ارفع الملفات الجديدة، وغيّر رقم CACHE في sw.js (مثلاً amr-riba-v2) ليتحدث على الهواتف.
